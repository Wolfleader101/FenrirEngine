# 01: describe-api records `@facade`, and Iris.Bindings writes the facade part

**What to build:** A native's doc comment may carry `@facade Class.Method`; describe-api records it, and Iris.Bindings writes `public static partial class <Class>` with one pass-through method per mark (spec: "The mark", "The generated facade part", "ADR-0043 amended", decisions 2, 3, 4, 6, 7, 8, 9).

- **`tools/describe-api/src/Natives.cs`**: the doc splitter takes `@facade Class.Method` (and `\facade`), the rest of its line, off the comment as it takes `@notrunning`, into a `Facade` string on `NativeFunctionDescription`, written as `"facade"` after `notRunning`. Fails naming the function: a mark that is not two C++-style identifiers joined by one `.` (`<function>: @facade names a public method as Class.Method`), and a second mark on one native. `SCHEMA.md`'s function table gains the `facade` row and its "Doc commands" paragraph the command. **Tests** (`tests/DescribeTests.cs`): `tests/Fixture/Natives.cpp` gains two marked natives (one giving a second class), the expected `Fixture.natives.json` carries their `facade`, and `FailingNatives.cpp` gains a malformed mark and a doubled one, each in the failure case's expected lines.
- **`packages/Iris/Tools/Iris.Bindings/src/Natives.cs`**: `NativeFunction` reads the optional `facade`; `BoundNative` gains `Facade` (class, method) and `FacadeParameters`, the declaration's parameters with `in` dropped (`in Vector3 force` becomes `Vector3 force`, passed as `in force`), everything else as declared. `Bind` refuses, in the per-native error list: a mark on a native whose declaration takes a type in `internal-structs` or a pointer (`<native>: @facade <Class.Method> cannot be public: it takes <type>`); after binding, two marks giving one class and method with the same `FacadeParameters` types (`<native> and <native>: both are @facade <Class.Method>(<types>)`); a facade class named as a mirror this binding or a used one generates, a bound type's C# type, or `[natives] class` (`<native>: @facade <Class> is the name of <what>`).
- **`CSharpWriter.cs`**: `Facades(binding, natives, bound)` returns one `<Class>.cs` per facade class named, in first-mark order: the "Generated by Iris.Bindings from <file>: do not edit" header, the natives' `using`s rule (`System` when a method takes a span, the binding's and the used namespaces the methods name), `namespace`, a `//` comment saying the hand-written part holds the class's doc and the rest, `public static partial class <Class>`, and per mark, in the description's order: the declaration's doc written exactly as `Natives` writes it (`Doc`, `<param>` for the unfolded parameters, `<returns>`), then `public static <Result> <Method>(<FacadeParameters>) => <natives class>.<Native>(<args>);`, each `in` and `out` argument spelled, the signature broken as `Signature` breaks one. `Generator.cs` writes the files beside the natives class and deletes a stale `<Class>.cs` as it does a mirror's; `HandWritten.cs` is unchanged (a static class has no instance field to check).
- **Fixture** (`tests/Fixture/Fixture.hpp` and `Fixture.natives.json`, hand-kept): three marked natives, one taking `in` a struct, one a span, two sharing a facade method name with different parameter types, on two classes; the expected generated `Generated/<Class>.cs` files checked byte for byte in `tests/BindingTests.cs`, and `tests/Checks/Sdk` compiles them against the real generator (a facade part is ordinary C# over the declaration, so the check is that it builds). **Refusal tests**: a mark on a native taking an `internal-structs` type, on one taking `void*`, two marks of one method and types, and a facade class named as a mirror, each asserting the diagnostic names the native and the mark.
- **README** (`packages/Iris/Tools/Iris.Bindings/README.md`): the "Natives" table gains the `<generated>/<Class>.cs` row; a paragraph after the declaration rules says what `@facade` generates, the `in` rule, that the hand-written class is `partial` and holds what a description cannot say, and the four refusals; the "Diagnostics" list gains them. `packages/Iris/docs/natives-description.md`: the `facade` row and the command in "Doc commands".
- **ADRs and glossary**: `docs/adr/0043-...md`'s facade bullet and its rejected option "Generated facades" each gain an *Amended by this change* note (the spec's wording: a facade is a hand-written part over a generated part; the generated part holds the natives whose public shape is the declaration's, each named by its `@facade`; the hand-written part holds what a description cannot say); its consequences gain one line. `docs/adr/0029-...md`'s facade bullet's *Amended by ADR-0043* note gains the same sentence. `GLOSSARY.md`'s *Facade* entry: "A static C# class over a package's generated native functions, its generated part the pass-throughs each native's `@facade` names and its hand-written part what a description cannot say: ...".
