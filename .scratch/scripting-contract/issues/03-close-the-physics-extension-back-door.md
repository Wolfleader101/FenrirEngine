# 03: Close the physics extension's back door

**What to build:** candidate H's behavioural part, on the seam ticket 02 built (spec: "The extension seam, without the back door"): no private includes, no process globals, one helper for the world, meshes through the world, `FrameFromWorld` without an app. Names are still hand-written here; ticket 08 generates them.

- **`PhysicsWorld::CreateCollisionMesh(std::span<const Math::Vec3>, std::span<const std::uint32_t>)` and `ReleaseCollisionMesh(CollisionMesh)`** forwarding to the owner's mesh store that `PhysicsWorld::Impl` already holds; `Physics::CreateCollisionMesh`/`ReleaseCollisionMesh` stay and share the store. Doc: meshes are the owner's and are shared by every world; a world only reaches them.
- **The mesh natives go through the world** like every other native. With no active physics world they return 0/false and warn once; `PhysicsWorld.cs`'s remarks say so. `OwnerFor`, `scriptedOwner` and `ownerMutex` go.
- **Extension state.** `struct PhysicsScripting` (name open) in the extension's `src/`: the debug `warned` set and its mutex, and `PhysicsWorld* WorldOf(const CallContext&, std::source_location = current())`, which returns the active scene's world or null, warning once per call site through `context.GetApp().Logger()` in debug builds. Every native takes `PhysicsScripting&` second and uses `WorldOf`; `WarnOnce` becomes a method on it; the `warned` process static goes. Every native with an output parameter zeroes it before any early return (today only `Depenetrate` and `GetJointState` do); `FrameFromWorldNative` checks for the entities it needs and warns like the rest.
- **The free function.** `Fenrir::ScriptingExtension PhysicsScriptingExtension()` declared in `include/FenrirPhysicsScripting/PhysicsScripting.hpp`, taking nothing, setting the state. `Physics::ScriptingExtension()`, its declaration, its doc block (which names the wrong C# class) and the forward declaration of `ScriptingExtension` go from `Physics.hpp`. The DemoApp and the physics scripting tests call the free function.
- **No private includes.** `PRIVATE ../src` goes from `Scripting/CMakeLists.txt`; `HasBodyComponent` is rewritten in the extension from public components (`RigidBody`, `Collider`, `CharacterBody`); nothing in the extension includes `PhysicsState.hpp`.
- **`FrameFromWorld`.** The C++ free function documents that a body that is not alive yields identity frames and does not warn; `lastInstalled`, `WarnThroughInstalledApp` and their use in `Physics.cpp`/`Joints.cpp` go. The native warns through its call context instead.
- `Physics.hpp`'s class doc and `Scripting/CMakeLists.txt`'s comments describe the new shape.
