# 13: `InstancedMeshRenderer` draws instance lists, and the asteroid ring shows it

**What to build:** Many copies of a mesh without an entity each (spec: "Instancing", "LightingDemo"; ADR-0051).

- **An instance-list asset** in FenrirAssets: transforms relative to the drawing entity and an optional colour each, with a revision bumped on edit.
- **`InstancedMeshRenderer { mesh, material, instances, castShadows, visible }`**; the renderer uploads a list when it is new or its revision changes, and draws it in every pass automatic instancing does. Per-instance colour is read through `Fenrir/Draw.glsl` and multiplies base colour in `lit`. No per-instance culling.
- **Scene 5, the asteroid ring:** a planet with Solar System Scope textures (CC-BY 4.0, fetched), 100k Poly Haven rocks of 3–4 kinds (fetched, CC0) with random scale, rotation and tint, a procedural starfield panorama generated by the demo, an emissive station with point lights, about 5k rock entities merged automatically beside the ring; the panel shows the count, the merging switch and draw and instance counts.
- The API description gains the component and the asset kind (generated output only).
